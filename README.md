# Divisao-e-Conquista
Entrada: n e depois n inteiros.

Saída: soma inicio fim, com índices começando em 0 (ou em 1, mas escolham um).

Desempate: entre intervalos de mesma soma, vale o que começa mais à esquerda e, se ainda empatar, o que termina mais à esquerda.

Intervalo vazio não vale. Se tudo for negativo, a resposta é o maior elemento.

## Configuração da máquina (medições)
- Processador: AMD Ryzen 5 5600G with Radeon Graphics
- Memória RAM: 32 GB
- Sistema operacional: Windows 11 pro
- Python: 3.15.1
